# 隐私说明（运营者审阅稿）

本稿用于开发预览。运营主体、联系邮箱、上线日期、服务器/CDN供应商与日志保存期限，须由运营者上线前确认。

## 1. 消费洞察文件

你在消费洞察页主动选择的 JSON 文件仅在当前页面内存解析和计算；不发给服务器、模型、统计服务或公开接口，也不写入浏览器持久存储。点击“清除样本”、离开该页面或刷新后需重新导入。分享页面网址不会分享样本。

请只使用自有或获授权的脱敏资料。账号使用代号；城市只到城市级；凭证引用使用本地导出行号等代号，不附客户身份、私聊、原始文件、截图、Cookie或令牌。程序检查格式与口径，无法独立核验授权或凭证。

## 2. 浏览器本地功能

框架的收藏、已读、外观、字体、最近搜索和反馈草稿保存在当前浏览器；滚动位置与返回状态使用会话存储。消费洞察样本不进入这些存储。清除浏览器数据后本地设置可能消失，不会跨设备同步。

## 3. 反馈与管理员功能

反馈内容、选填邮箱、页面地址与主动附上的截图会发到服务器；配置了内部飞书通知时可转发给运营者。为防滥用，系统使用网络地址与浏览器类别计算不可逆的限流标识。请勿通过反馈提交私人消费样本或客户资料。

## 4. 日志、模型与采集

此版本未添加访客统计。服务器、反向代理与 CDN 的日志行为及保存期限取决于部署配置，运营者需上线前披露。公开资讯的模型处理仅在后台任务发生；打开页面不调用模型。开发时采集、模型调用和外部推送关闭。

## 5. 外部来源

点击原文后适用对应平台的隐私规则。普通资讯页的第三方图片/媒体沿用框架处理方式；消费洞察页仅展示文字记录，不自动读取笔记原文、图片或凭证。更正、查询、删除请求可先通过反馈页提交；运营者须在上线前补全正式联系方式。
