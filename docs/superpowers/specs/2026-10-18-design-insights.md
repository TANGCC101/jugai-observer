# 局改观察：站点定制设计

服务在小红书获客、以设计服务费为收入的独立精装房局部改造设计师。用户已授权在独立分支实施并提 PR；站名暂用「局改观察」。用户暂无城市、价格带与账号名单，要求先选高流量候选；没有可比流量证据时只能给出有代表性的候选，不能伪称流量排名。

## 交付与边界

- 沿用 API / worker / SSR web 与唯一 publication 读取层。站点配置、分类、主题、提示词在 site/ 与 industry/；本站的消费洞察功能独立放在 modules/design-insights/。
- 首页连接三条工作线：小红书消费洞察、X AI 动态、国内 AI×设计。来源目录标明接入方式、授权条件、失效降级与覆盖限制。
- 小红书没有已验证的全站停留时长或设计服务费接受度数据。提供浏览器内的脱敏 JSON 导入与统计；文件只保留在当前页面内存，刷新即清除，不发给服务器或模型，不进入公开 API、RSS、MCP。没有导入时全部为空，不播种示例事实。
- 每条笔记保留 URL、采样时间、发布时间、凭证引用、来源方式、城市、账号代号、风格、内容形式、投流状态、观察窗口。统计可按城市/账号/窗口/投流筛选；不同形式分别比较。去重、无效计数与不可信停留值在导入时拒绝。
- 点赞、收藏、评论、分享、阅读各自可缺失。互动事件/阅读仅使用五项齐全且阅读数大于零的笔记，显示有效样本数；不是独立用户率、不是停留代理。停留只接受自有或授权后台导出的明确秒数；公开人工观察不能携带停留值。
- 服务价格记录分卖方报价、预算自述、接受报价、拒绝报价、实际支付。记录币种、计费单位、城市、服务范围、证据引用；逐条展示，不跨单位、城市或服务包汇总为“市场接受价格”。报价不等于接受，接受不等于成交。
- 原始导入记录属于可追溯输入，系统无法独立验证凭证。页面明确区分记录、可复算统计、待验证推断；不自动生成风格胜出、爆款因果、全国价格区间等结论。
- 资讯热度沿用框架的 48 小时独立来源指标，始终解释为本站样本内讨论度。隐藏卡片 AI 评分，理由称「阅读价值」；公开出口中的 score 仍是编辑评分。

## 来源策略

优先已有官方 RSS；X、公众号和社区通过已有 external 推送进入审核隔离区，第三方采集器默认不启用。官方接口只在持有相应权限、预算和使用许可后由运营者外部任务接入；不添加 Cookie、登录绕过或验证码方案。官网 RSS 作为 X 消息的替代来源，不能冒充 X 覆盖；公众号以作者授权摘要/原文索引降级，论坛以允许的 RSS/授权人工记录降级。无可信日期不发布；全文开关保持 false。

## 验收

验证导入的缺失值、权限、重复、日期、计数、分母、窗口筛选和价格语义；配置与公开接口契约一致。运行 npm run typecheck、npm test、网页构建与网页测试；启动本机无外部调用站点，运行 node scripts/smoke.ts，并检查新增页面的桌面/移动入口。门槛数字不改，模型真实效果留待用户标注样本校准。条款为审阅稿，运营主体、邮箱和上线日期待用户决定。
